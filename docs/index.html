核心能力

不是简单的代理切换，而是把解析、优选、连接串成一条可控链路。

01 / SPEED

Cloudflare IP 优选

内置官方 IP 段并可在线刷新，对候选节点并发 TCP/TLS 测速，只选证书校验通过且延迟最低的 IP。

02 / SECURITY

DNS Security

DoH / DoT 加密解析，固定 bootstrap IP + SNI；IANA 根信任锚本地 DNSSEC 链式校验，篡改即判 bogus。

03 / PRIVACY

防污染与缓存

多解析器应答一致性比对、TTL/否定缓存、SERVFAIL 检测；严格模式下校验失败直接拒绝解析。

04 / FALLBACK

网络自适应

固定加密 DNS IP 不可达时自动回退到国内 DoH，TLS 证书仍严格校验，避免直接退回明文系统 DNS。

05 / SAFE TLS

端到端不降级

本地代理只负责选 IP 和转发字节，TLS 仍由 WebView 对真实域名校验，不做中间人、不解密流量。

06 / OPEN

开源可审计

纯 Dart 网络核心与 Electron/Flutter 双端代码全部开源，逻辑透明，可自行构建验证。

它怎么工作

WebView 无法直接指定 DNS/IP，BigJump 在本机开一个小代理接管这条链路。

① 用户访问域名→ ② 本地代理拦截→ ③ 安全 DNS 解析→ ④ 并发测速优选 IP→ ⑤ 端到端 TLS 连接

使用前须知

· Windows 版解压后运行 BigJump.exe，无需管理员权限；Android 版需允许安装未知来源应用。

· Android 代理注入依赖 Android 10（API 29）+ 可更新的 WebView；旧系统可浏览但无法启用优选。

· 首次启动会探测加密 DNS 端点，若主端点不可达会回退到国内 DoH，状态栏会明确显示当前解析状态。

· 工具用途请遵守当地法律法规与目标站点服务条款。
